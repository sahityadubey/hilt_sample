
# 📱 Hilt Sample Project with MVVM Architecture (Kotlin)

Welcome to the **Hilt Sample App** 🚀 — a basic Android app built with Kotlin using **Hilt** for dependency injection, **Room** for local caching, **Retrofit** for networking, and the **MVVM** architecture pattern. This project is great for anyone learning how to integrate these tools in a clean Android project setup.

---

## 🧰 Tech Stack & Libraries

- 🧠 **Hilt** – for dependency injection
- 📦 **Retrofit** – for making network calls
- 🏠 **Room** – for local database caching
- 🔄 **LiveData** + **ViewModel** – for observing UI state
- 🧭 **Navigation Component** – for in-app navigation
- 🧪 **JUnit & Espresso** – for testing

---

## 🗂 Project Structure

```
com.sahitya.hilt_sample
│
├── di               # Hilt modules for DI setup
├── model            # Data models (e.g., Blog.kt)
├── repository       # Repository layer to manage data operations
├── retrofit         # Retrofit interfaces and mappers
├── room             # Room database, DAOs and mappers
├── ui               # Activities, Fragments, and ViewModels
├── util             # Utility classes (e.g., MyApplication.kt)
```
